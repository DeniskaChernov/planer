# Founder OS

Персональная операционная система основателя: проекты, задачи, идеи, профиль и контекстный GPT-помощник.

## Локальный запуск

```bash
npm install
npm run dev:all
```

Без переменных окружения приложение работает в локальном режиме и сохраняет данные в `localStorage`. Для полной проверки скопируйте `.env.example` в `.env`, укажите PostgreSQL и OpenAI API key.

## Railway

1. Создайте новый Railway project из репозитория.
2. Добавьте PostgreSQL service — Railway автоматически передаст `DATABASE_URL` приложению.
3. В Variables приложения добавьте `OPENAI_API_KEY`.
4. Опционально задайте `OPENAI_MODEL`; по умолчанию используется `gpt-5.4-mini`.
5. Deploy. Railway автоматически использует корневой `Dockerfile`, соберёт frontend и backend и запустит единый Node-сервер.

При первом запуске сервер сам создаёт таблицы `users`, `conversations` и `messages`. Профиль, состояние проектов и история разговоров сохраняются в PostgreSQL и не зависят от перезапусков контейнера или повторного входа в приложение.

## Важное о текущем MVP

Приложение пока рассчитано на одного владельца и использует постоянный идентификатор `founder`. Перед публичным многопользовательским запуском необходимо добавить авторизацию и серверную проверку сессии.
