# Founder OS

Общая операционная система для основателя, семьи и команды: проекты, задачи, идеи, профиль и контекстный GPT-помощник.

## Первый вход

После первого деплоя откройте приложение и выберите «Новый аккаунт». Создайте персональный ID, PIN и общее пространство. В разделе «Люди» появится код приглашения: жена или участник команды создаёт собственный ID, выбирает «У меня есть код приглашения» и входит в то же пространство.

Поле `Finance ID` связывает профиль Planner с идентификатором пользователя Finance без объединения двух баз данных. PIN хранится только как bcrypt-хэш, авторизация — в HttpOnly cookie.

Приложение является installable PWA: на Android его можно установить из меню браузера, на iPhone — через «Поделиться → На экран Домой».

## Локальный запуск

```bash
npm install
npm run dev:all
```

Без переменных окружения приложение работает в локальном режиме и сохраняет данные в `localStorage`. Для полной проверки скопируйте `.env.example` в `.env`, укажите PostgreSQL и OpenAI API key.

## Railway

1. Создайте новый Railway project из репозитория.
2. Добавьте PostgreSQL service — Railway автоматически передаст `DATABASE_URL` приложению.
3. В Variables приложения добавьте `OPENAI_API_KEY`.
4. Опционально задайте `OPENAI_MODEL`; по умолчанию используется `gpt-5.4-mini`.
5. Deploy. Railway автоматически использует корневой `Dockerfile`, соберёт frontend и backend и запустит единый Node-сервер.

При первом запуске сервер сам создаёт таблицы аккаунтов, пространств, участников, сессий и AI-диалогов. Профиль и общее состояние сохраняются в PostgreSQL и не зависят от перезапусков контейнера или повторного входа в приложение.

## Важное о текущем MVP

Перед широким публичным запуском рекомендуется дополнительно включить rate limiting, восстановление PIN и аудит действий участников.
